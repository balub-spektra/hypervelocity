# .copilot-tracking/

This folder is where the HVE RPI workflow (Research → Plan → Implement →
Review) writes its working artifacts: research documents, plans, phase
details, change logs and review records, each under a dated subfolder.

It starts empty. It is listed in `.gitignore` and is not part of the shipped
codebase — see the root `README.md` and `docs/architecture.md` for the
actual pipeline.
